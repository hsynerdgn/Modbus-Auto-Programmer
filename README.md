# Modbus-Auto-Programmer
Modbus Auto Programmer for XKoren XFK Series Variable Frequency Drives

minimalmodbus module is needed for this code to function.


Run the main.py command from the command terminal as "python main.py"


main.py arguments:
--port            serial communication port of the USB-RS485 converter


--dictionary            dictionary files directory, set as dict.csv as default


--values            value files for parameters to be changed, an example file can be found in the repository


--timeout            communication timeout limit in seconds, set as 1 seconds as default
